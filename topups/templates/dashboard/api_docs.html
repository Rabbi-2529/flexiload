Authentication

Base URL: {{ request.scheme }}://{{ request.get_host }}/api/

Login and obtain a token

POST /api/auth/login/ 
{
  "email": "operator@example.com",
  "password": "your-password"
}

Use the returned token on every protected request:

Authorization: Token YOUR_TOKEN

Send a top-up

POST /api/transactions/send/ 
{
  "sim_profile_id": 1,
  "product": "flexiload",
  "phone_number": "01712345678",
  "amount": 50,
  "idempotency_key": "order-2026-0001",
  "retry_failed": true
}

Products: flexiload, offer, postpaid, prepaid, regular, topup, and GP-only skitto.

The optional write-only pin replaces the encrypted PIN saved for the selected SIM.

Idempotency and automatic retry

Use the Laravel sms_id as the idempotency_key. Do not generate a new key for a retry.

Sending retry_failed: true has these effects:

  • A new idempotency key creates a new transaction.
  • An existing failed transaction is executed again.
  • Existing processing or successful transactions are returned without dialing again.

Retry using the transaction UUID

POST /api/transactions/{uuid}/retry/

No request body is required. This endpoint uses the original SIM, number, amount, product and idempotency key. 

Authorization: Token YOUR_TOKEN
Content-Type: application/json

Transaction statuses

  • pending — waiting to be processed.
  • processing — accepted and waiting for carrier SMS.
  • success — carrier confirmed the recharge.
  • failed — carrier or modem rejected the request.

Transaction history

GET /api/transactions/

Returns paginated transaction history. Use ?page=2 for later pages.

GET /api/transactions/{uuid}/

History responses include:

  • carrier_transaction_id
  • message
  • targeted_number
  • modem_response
  • error_message
  • retry_count
  • last_retried_at

cURL examples

Send or retry with the same idempotency key

curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/transactions/send/" \
  -H "Authorization: Token YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"sim_profile_id\":1,\"product\":\"flexiload\",\"phone_number\":\"01712345678\",\"amount\":50,\"idempotency_key\":\"order-2026-0001\",\"retry_failed\":true}"

Retry using transaction UUID

curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/transactions/TRANSACTION_UUID/retry/" \
  -H "Authorization: Token YOUR_TOKEN" \
  -H "Content-Type: application/json"

curl "{{ request.scheme }}://{{ request.get_host }}/api/transactions/" \
